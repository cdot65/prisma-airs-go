Every API method takes a context. HTTP clients are injectable, OAuth token
refresh is automatic, and errors retain status and wrapped causes. Gateway
workspaces must already exist; its client covers management CRUD and lifecycle
operations. Inference, streaming, and workspace provisioning are outside its scope.
